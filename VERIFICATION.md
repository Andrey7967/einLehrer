- По согласованному объёму смысловой набор включает первый раздел полностью: 77 вопросов, 154 разметки и 77 пояснений после чтения вопросов и всех их вариантов.

- В остальных разделах нет подстановки алгоритмических подсказок под видом смыслового разбора.
- DOM-тест проверяет посимвольную сохранность всех 5 104 текстов с обоими наборами и с подсветкой/без неё.
- Проверены смена набора без сброса сессии, соответствие фактических выделений авторской разметке, появление пояснения только после ответа, независимость редакторов и отсутствие подстановки в неразобранных главах.
- Полный банк вопросов, варианты, отметки правильности и изображения не менялись.

## Перенос

- 961 вопрос, 14 глав, 4 143 варианта ответа, 78 изображений.
- В каждой главе непрерывная нумерация, у каждого вопроса один зелёный ответ.
- 7 206 текстовых строк сопоставлены с координатами и содержимым исходного PDF. Потерянных и дублированных строк нет; отдельно исключены только заголовки глав.
- Цвет каждого ответа повторно проверен по символам PDF. Каждое изображение имеет соответствующую область исходного изображения.
- Повреждённые Unicode-отображения лигатур восстановлены по GSUB встроенного шрифта: `ft`, `ti`, `tt`. Восстановление не использует словарь или генерацию текста. Исходный PDF не изменён.
- Сравнение извлечения pdfplumber и pypdf: необъяснённых расхождений нет. Эквивалентная лигатура `ﬂ` на странице 2 записана отдельно.
- SHA-256 исходного PDF: `a32ee3a6504a6cc0d4d7b1ce64f5f837ecff19126b3e7bb3f0f4dd5fc7cc8915`.

## Интерфейс и логика

- Текст всех 5 104 вопросов и вариантов после отображения точно совпадает с банком как с подсветкой, так и без неё.
- Проверены ошибка без автоматического перехода, выделение правильного ответа и его ключевых слов, автоматический переход после правильного ответа, восстановление сессии.
- Проверены редактирование подсказок без изменения текста, сохранение отметок сверки, общий тест из 14 разных глав, итог 14/14 и тест по отдельной главе.
- Перемешивание сохраняет все вопросы без повторов; исходный массив не меняется.
- Повреждённые диапазоны и несовместимые сессии отклоняются.
- Production-сборка и TypeScript-проверка проходят.
- Проверка согласованности package-lock через `npm ci --dry-run --offline` проходит.

## PWA

Тест service worker в среде с имитацией Cache API проверяет сохранение оболочки, обрыв загрузки, повторное использование скачанного, готовность только после завершения, офлайн-выдачу банка, картинки, PDF, последней страницы и навигационный fallback. Проверяется размещение в подкаталоге.

## Ограничения проверки

Полная ручная визуальная сверка всех вопросов не выполнена. Исходные страницы доступны в режиме сверки приложения. Большинство ключевых слов — автоматические предложения, доступные для ручного уточнения.

Настоящий браузер не удалось использовать: запуск из среды завершился ошибкой; управление через интерфейс прекращено из-за невозможности надёжно определить текущий URL. Поэтому мобильная вёрстка, установка PWA и реальная браузерная работа офлайн не считаются проверенными. DOM-тесты и тест service worker не выданы за браузерную приёмку.
